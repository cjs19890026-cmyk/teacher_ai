## 🎮 玩法

1. 选择 **游戏模式**：单人闯关或双人 PK。
2. 选择 **年级**、单元或点 **📝 自选**勾选词汇。
3. 选择 **难度**（简单 / 中等 / 困难）和页面主题。
4. 点 **▶️ 开始游戏**，点击两张卡片配对：**英文 ↔ 中文**。
5. 单人模式在 60 秒内完成所有配对；PK 模式中，谁先完成谁获胜。

### 得分规则

- ✅ 配对成功 → **+10 分**
- ❌ 配对失败 → **−5 分**（最低 0 分）
- ⏱️ 全部配完剩余时间 → 每秒 **+2 分**奖励

### 双人 PK 规则

- 双方看到的词汇、卡片位置与空白格完全相同。
- 双方独立操作、独立计分和统计正确率，共享 60 秒倒计时。
- 任一玩家率先完成全部配对立即获胜；若时间结束，则先比较完成对数，再比较得分。

### 添加新年级

词汇数据以 `VOCAB_DATA` 内嵌在 `word-match.html` 中，并按年级、单元自动整理。新增词汇时，按以下结构补充数据即可：

```js
{
  unit: '四年级上册Unit 1 单元名',
  words: [
    { en: 'word', cn: '单词' }
  ]
}
```
