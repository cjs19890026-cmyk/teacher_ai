# 📚 单词消消乐 — Word Match Game

人教PEP 小学英语单词配对游戏，支持 **三年级 ~ 四年级** 多册教材，无需网络、打开即玩。

> 🌐 **在线体验**：部署完成后访问
> 
> ```
> https://cjs19890026-cmyk.github.io/teacher_ai/word-match.html
> ```
> 
> 📦 纯 HTML 单文件，下载即可离线使用。

---

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 📖 **多年级词库** | 三上 / 三下 / 四上，含各单元全部重点词汇 |
| 🎯 **选词练习** | 侧边面板勾选想练的单词，词不够自动补随机 |
| 🌱 **三档难度** | 4×4 / 5×5 / 6×6 棋盘，对应不同配对数 |
| 🔊 **真人发音** | 点英文卡片自动朗读，支持多种语音切换 |
| ⏱️ **60 秒挑战** | 倒计时 + 得分规则（✅ +10 / ❌ −5 / ⏱️ 剩余秒 +2） |
| 📊 **实时统计** | 得分、正确率、进度条一目了然 |
| 📱 **全平台** | Mac / Windows / iPad / 手机 / 教室大屏均适配 |
| 🏔️ **离线可用** | 单 HTML 文件，无需网络，下载到本地就能玩 |

---

## 🎮 玩法

1. 选择 **年级** → 点 **📝 自选**勾词 或 直接开始
2. 选择 **难度**（简单 / 中等 / 困难）
3. 点 **▶️ 开始游戏**
4. 点击两张卡片配对：**英文 ↔ 中文**
5. 60 秒内配对所有单词，拿高分！

### 得分规则

- ✅ 配对成功 → **+10 分**
- ❌ 配对失败 → **−5 分**（最低 0 分）
- ⏱️ 全部配完剩余时间 → 每秒 **+2 分**奖励

```js
'四上': {
    name: '四年级上册',
    units: [
        { id: 1, name: '单元名', words: [
            {en: 'word', zh: '单词', emoji: '📖'},
            // ...
        ]},
        // ...
    ]
}
```
